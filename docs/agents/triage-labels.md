# Triage labels

The skills speak in terms of five canonical triage roles. This table maps each role to the label string this repository's issue tracker uses.

| Label in mattpocock/skills | Label in our tracker | Meaning                                               |
| -------------------------- | -------------------- | ----------------------------------------------------- |
| `needs-triage`             | `needs-triage`       | The maintainer must evaluate this issue.              |
| `needs-info`               | `needs-info`         | The issue waits on the reporter for more information. |
| `ready-for-agent`          | `ready-for-agent`    | The issue is fully specified and ready for an agent.  |
| `ready-for-human`          | `ready-for-human`    | A human must implement this issue.                    |
| `wontfix`                  | `wontfix`            | No one will act on this issue.                        |

When a skill mentions a role, use the label string from this table.

Because this repository tracks issues as local Markdown, these strings are written as a `Status:` line near the top of each issue file — see [the issue tracker](issue-tracker.md).
