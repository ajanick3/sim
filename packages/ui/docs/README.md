# Reference layout

`reference-board-layout.jpg` is the visual target this library's
Regions are building toward — a rounded felt court, a single dominant
Active per side, a curved centre divider, a chess-clock-shaped rail on
the right (adapted: this game has no clock), a settings gear, and the
Hand as a fanned row of full cards along the bottom.

It's a style and layout reference, not a feature list: this game has
no chat, no AI-opponent panel, and no per-turn clock, and those parts
of the screenshot are not being reproduced.
