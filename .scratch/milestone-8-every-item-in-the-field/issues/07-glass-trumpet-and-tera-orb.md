# Glass Trumpet & Tera Orb

Type: task
Status: resolved

*"You can use this card only if you have any Tera Pokémon in play. …"*
(`Glass Trumpet`) and *"Search your deck for a Tera Pokémon, reveal it,
and put it into your hand. …"* (`Tera Orb`).

- [x] A recorded decision on whether these cards can be run in full, or
      must be refused

## Resolution

Refused, both. Both gate on "a Tera Pokémon," the same concept
`data/cards.json` carries no field for that got `Briar` refused —
[ADR 0033](../../../docs/adr/0033-briar-is-refused-for-a-concept-the-artifact-lacks.md)
applies unchanged; no new ADR is needed for the same reasoning applied
to two more cards.

No `known_trainer` entries were added. Coverage does not move.
